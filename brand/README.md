# Brand assets (temporary)

Hand-authored SVGs (true vectors — not AI raster). Scale to any size.

| File | Use |
| --- | --- |
| `yark-mark.svg` | App / favicon primary (teal Y on dark) |
| `yark-mark-mono.svg` | Light-on-dark mono |
| `yark-mark-hex.svg` | Alternate hex frame |
| `yark-mark-signal.svg` | Alternate signal bars |
| `yark-wordmark.svg` | Web header / docs (dark) |
| `yark-wordmark-light.svg` | Web on light backgrounds |

## Sizes

- **Web favicon / tray:** export PNG 16, 32, 48 from `yark-mark.svg`
- **electron-builder Windows icon:** need `.ico` multi-size (16–256); convert from the mark SVG
- **GitHub / site hero:** use `yark-wordmark.svg` directly or PNG @2x

Open any `.svg` in a browser or Figma/Inkscape to preview.

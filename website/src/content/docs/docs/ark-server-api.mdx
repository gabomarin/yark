The workspace **Ark Server API** tab is optional support for the community
[ArkServerApi](https://github.com/ArkServerApi/AsaApi) stack (Version.dll / loader +
plugins). It is **not** Wildcard, not CurseForge `-mods=`, and YARK does not endorse
third-party DLLs.

<Aside type="caution" title="Experimental">
  ASA game patches often break the community API until authors publish a new build.
  Use a non-production profile first, and keep world backups.
</Aside>

## What you can do

| Action | Notes |
| --- | --- |
| **Install** | Downloads the latest API release into this server’s Win64 folder (cached under YARK app data) |
| **Remove** | Deletes API / loader / plugins; game files stay. Stop the server first |
| **Load on Start** | Off by default. Prefer Version.dll so Start stays on the normal game process |
| **Add plugin zip** | Installs into `ArkApi\Plugins\<Name>`; disable moves to `Disabled_Plugins` |

## Honesty

- Windows only.
- While Load on Start is on, Overview / workspace may show **Loading Ark Server API…** until the server window is ready.
- SteamCMD **Update / Verify** can overwrite Win64 community files (`Version.dll`, `AsaApiLoader.exe`, `ArkApi\`) because sync only excludes `ShooterGame\Saved`. Re-check the tab (or Install again) after an update if Load on Start fails. Move installation copies the whole tree, so API files move with the server when they were present on the source.
- Full engineering notes: repo `docs/asa-api.md`.

YARK is a **Windows desktop app** for managing **local** ARK: Survival Ascended dedicated servers.
These docs are written for operators using the public prerelease — not for reading the Electron source tree.

## What YARK is responsible for

- Multiple **server profiles** in one app (install path, ports, passwords, mods, cluster fields)
- **SteamCMD** install / update / verify of ASA dedicated files into each profile
- **Start / stop / restart / force close**, with readiness gated on RCON
- **Backups** (world / players / INI), including portable export/import and critical-path snapshots for safe update & restart
- **Move installation** and opt-in **Auto-start with YARK**
- **INI** editing (visual + raw) and an on-demand **configuration assistant**
- **CurseForge mod IDs** on the launch line (`-mods=`), plus metadata lookup
- **Logs** (events, runtime, update files, backup history) with retention for YARK-owned data
- **YARK updates** from GitHub Releases (Settings / accented sidebar version)
- **Cluster** compliance hints (shared Cluster ID + directory)

## What it is not

- Not a cloud host, game client launcher, or official Wildcard product
- Not a CurseForge mod downloader/installer
- Not production-ready — builds are **unsigned prereleases**
